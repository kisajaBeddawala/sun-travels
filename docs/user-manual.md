# Sun Travels user manual

## Save and view a hotel contract

1. Open **Hotel contracts** and select **New contract**.
2. Select an existing hotel. To add a hotel, select **Add hotel**, enter its name and optional city, and select **Add and select hotel**.
3. Enter the start date, end date and markup percentage. The end date is the last room night the agreement covers.
4. Enter the room type name, the USD rate per adult per night, the number of rooms allocated, and the maximum adults in one room. Use **Add room type** to enter another set of rates and allocations.
5. Select **Save contract**. The detail view shows your saved agreement. You can reopen it from **Hotel contracts**.

If the form highlights a field, correct the value and submit again. Room type names must be unique within an agreement. The start and end dates can be the same.

## Search and read a quote

1. Open **Room search** and enter the check-in date and number of nights.
2. Add one entry for every requested room and specify its own adult count. Use **Remove** to drop a room from the request.
3. Select **Search rooms**. Read the hotel, room type, availability, and total USD price for the whole stay. An unavailable offer shows the capacity or allocation reason. An empty result means there is no contract that covers the occupied nights.

For the demo agreement, search June 10, 2027 for three nights with two adults in Room 1 and one adult in Room 2. The Standard quote is USD 362.25 and the Sea View quote is USD 569.25. Enter three adults in Room 1 to see Standard fail its adult limit while Sea View can still fit the request.
